    Brabo

    A team of AI agents takes your application from brief to deploy; the merge is always yours.

    • Use Brabo install it, open your first project and follow a session.
    • Understand how it works the agents, the approval policy and the immutable record.
    • Replicate the method organize several repositories for a team of agents.
    🛑 Nothing leaves without approval
    Every external effect is born as a proposed_action and goes through the project's policy; merging into a protected branch is always yours.
    🧱 The agent is untrusted by construction
    Ceilings on iterations, corrections and budget, in code. A prompt is not a guarantee; code is.
    📜 Everything recorded and immutable
    An append-only event log with dense numbering per session: auditable cost and verifiable backup.
    👥 One team from brief to deliverable
    Creative, PO, Architect, Dev Lead, devs per module, Infra, QA and SecOps over a real git repository.
