    Operations

    创建一个安装的第一个账户，且已验证

    Request

    供一行命令安装器使用，它运行在未配置邮件传输的环境中：生成的 .env 不含任何邮件变量，MAIL_TRANSPORT 回落为 log，而常规注册会等待一封永远不会到达的邮件。账户一出生即已验证，因为运行安装器的人已经证明了比控制一个邮箱更强的东西——他们控制着这台机器、.env 和 Docker 守护进程。常规注册不受影响。当安装中已有任何用户时以 409 拒绝：条件针对的是安装，而非这个邮箱，因此迁移恢复会通过同一检查让这一步保持静默。密码绝不在此生成，除了 argon2id 哈希外也绝不存储在任何地方；个人 workspace（RN-410）在同一事务中创建。

    Security
    service-token
    Bodyapplication/jsonrequired
    emailstringrequired

    所有者的邮箱，在 TTY 中输入。在写入任何内容之前进行规范化；安装器会把它记录在标记中，因为邮箱用于识别身份，并不是机密。

    Example:"voce@exemplo.dev"
    senhastringrequired

    无回显读取，并由安装器确认。用完即弃——绝不写入 .env、标记或日志，也绝不由任何代码生成：不存在账户以脚本选择的密码诞生的路径。最低要求是领域策略，与注册使用的是同一段代码；这里的最大长度是对 argon2id 的保护，而不是策略。

    Example:"uma frase longa e minha"
    nomestring

    显示名称。省略时：个人 workspace 的名称回落为邮箱的本地部分（RN-410）——不会编造任何东西。

    Example:"Fulana de Tal"
    POST
    /internal/first-account
    Payload
    {
  "email": "voce@exemplo.dev",
  "senha": "uma frase longa e minha",
  "nome": "Fulana de Tal"
}

    Responses

    Bodyapplication/json
    userIdstring, (uuid)required

    所创建的用户。

    Example:"01JC4Z0000USUARIO0000000001"
    emailstringrequired

    规范化后的邮箱——实际写入的内容，可能与输入的不同。安装器会把它记录在标记中。

    Example:"voce@exemplo.dev"
    workspaceIdstring, (uuid)required

    在同一事务中诞生的个人 workspace（RN-410），该账户为其 owner。没有它，安装结束时会有一个能用的登录，而仪表盘中的“新建项目”却无处可建。

    Example:"01JC4Z0000WORKSPACE00000001"
    Response
    {
  "userId": "01JC4Z0000USUARIO0000000001",
  "email": "voce@exemplo.dev",
  "workspaceId": "01JC4Z0000WORKSPACE00000001"
}
