    part 2 RN-1031 23 Feature regression and run links (RN-1031..1035, RN-1043..1045); Publishing npm packages (RN-1042); Merge dependency across repositories (RN-1047..1050); The regression decision report (RN-1051..1053); The trigger waits for the stamp and the signature before going red (RN-1066); The change panel (RN-1054..1056, ADR 0278)
