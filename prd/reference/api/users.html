    Operations

    Lista as próprias chaves de dispositivo de MÁQUINA do usuário autenticado

    Request

    Por conta, sem projeto no caminho (RN-611): a instalação de uma linha cria uma chave de máquina antes de existir qualquer projeto, e toda outra listagem é por projeto. Devolve SÓ chaves de máquina (especie: "maquina", projectId: null) e SÓ as do chamador — chaves de projeto ficam na listagem do projeto delas, e ninguém vê chave de outro usuário (RN-519). Chaves revogadas ENTRAM: registrar uma chave de máquina nova revoga a anterior (RN-552), e é nesta lista que isso aparece. lastUsedAt é uso registrado, nunca conexão viva; nulo quer dizer que a chave nunca foi usada.

    Security
    bearer
    GET
    /users/me/machine-device-keys
    Payload
    // No request payload

    Responses

    Bodyapplication/json
    Array [
    idstringrequired
    Example:"01JC4Z0000CHAVE000000000001"
    namestringrequired
    Example:"laptop"
    projectIdobject or nullrequired

    Nulo = chave de MÁQUINA (ADR 0154): vale para qualquer projeto do dono dela, e não só para este. Ver especie.

    Example:"01JC4Z0000PROJETO000000001"
    especiestringrequired

    projeto = presa ao projeto desta rota (ADR 0118). maquina = descreve a MÁQUINA (ADR 0154) e aparece na listagem de todo projeto que ela atende — revogá-la derruba o agente local em todos eles.

    Enum:"projeto""maquina"
    Example:"projeto"
    createdAtstring, (date-time)required
    Example:"2026-08-27T12:00:00.000Z"
    revokedAtobject or nullrequired

    Nulo = ativa. Revogada continua aparecendo na lista.

    Example:null
    lastUsedAtobject or nullrequired

    Nulo = nunca usada — o sinal de uma chave órfã (aba fechada no meio do fluxo de configuração automática do runner).

    Example:null
