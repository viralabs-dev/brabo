# Brabo 是如何构建的

**适合谁：** 想在自己的产品中复制 Brabo **工作方式**的人，无论是否使用 AI 智能体。你不需要了解项目的历史。

**读完之后你可以：**
- 搭建一个带有一个史诗和两个任务的看板，其中一个任务已可开始；
- 运行一轮包含调研与执行、并以一个 PR 结束的轮次；
- 把每条业务规则关联到一个文件和一个测试；
- 复制模板和示例智能体。

**阅读时间：** 约 20 分钟；每页 3 到 5 分钟。

## 结构与方法

路径[跨多个仓库编排一个产品](../orquestrar-repositorios/index.md)教的是**结构**：如何拆分产品，以及仓库之间如何相连。本路径教的是**方法**：工作如何进来、如何推进、如何出去。只复制结构的人，得到的是十一个仓库，却没有节奏。

这里的示例都是虚构且中立的。有真实证据的地方，文中会链接到一个公开的 PR，例如发布了结构路径的 [`brabo` 的 PR 79](https://github.com/viralabs-dev/brabo/pull/79)。
