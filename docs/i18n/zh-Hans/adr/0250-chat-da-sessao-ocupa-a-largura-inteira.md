# ADR 0250 — 会话聊天占满整个宽度

- **状态：** 已接受
- **日期：** 2026-11-03
- **扩展：** [ADR 0248](0248-conteudo-das-paginas-ocupa-a-largura-inteira.md)，延伸到会话界面。

## 背景

ADR 0248 去掉了项目标签页和账户页的列，但把会话留在了范围之外。测量显示，即使在宽屏上，时间线、composer 和待处理项也被限制在 780px；所有者（11/03）要求聊天占满全部空间。

## 决定

1. 会话的时间线、气泡、回合状态条、composer、提示和待处理项占满聊天区域的整个宽度，保留现在的横向 padding。
2. **组件**的界限（560px 的问题卡片、标签和 chip）以及侧边的上下文面板保留。

## 后果

- 在宽屏上，气泡中的文本行会被拉伸。
