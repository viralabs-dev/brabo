# ADR 0241 — 侧边栏采用 shadcn 的 `sidebar-07` block

## 状态

**已接受。** 2026-11-02（AT-714；v7 经所有者批准）。修订
[ADR 0211](0211-uma-navegacao-so-a-sidebar-absorve-o-trilho.md)——它
仍然有效，不被编辑——仅涉及宽度和收起机制。

## 背景

ADR 0211 使侧边栏成为唯一的项目导航，展开 264px，收起 62px（代码标签页：框架 312px，收起时 110px）。v7（线性设计和 shadcn 的 blocks）已获批准，侧边栏改用 `sidebar-07` block。

## 决定

- 宽度：展开 **256**，收起 **48**（此前为 264/62）。
- 代码标签页：框架 **304px**（256 + `CodeShell` 轨道的 48），侧边栏收起时 **96**（48 + 48）。是宽度之和，并非在浏览器中测得。
- 保留已有的收起状态（记住偏好）和快捷键 Ctrl/Cmd+B，现在由该套件提供。
- 该套件会写入 cookie `sidebar_state`；它被写入后**没有读取者**（状态的来源仍是 `lib/sidebar-state`）。
- 所有者的决定（03/11，修订 02/11 的决定）："设置"是侧边栏中的**一个**条目，与其他标签页一样——侧边栏不增加子项，也不变长。各分组——模型、项目、人员和高级——是页面内的**标签页**，位于顶部的条带中，每个都位于 `?tab=settings&group=<grupo>`。实现属于 AT-719。
- 所有者的决定（03/11）：页脚变为 `sidebar-07` 的用户菜单（触发器 = 带头像、邮箱和角色的卡片；条目：账户、主题和退出；收起时只显示头像，菜单在一侧打开）。"收起菜单"、容器、Providers 和开销仍是页脚的链接。项目的标签页变大（正文、32px、16px 图标），分组之间有分隔线。
- Lucide 图标。ADR 0211 关于内容所作的决定（分组、活动标签页、键盘、计数器绝不相加）仍然有效。

## 后果

shadcn 套件的依赖已存在于 web 中；没有读取者的 cookie 是已声明的缺口，而非偶然。
