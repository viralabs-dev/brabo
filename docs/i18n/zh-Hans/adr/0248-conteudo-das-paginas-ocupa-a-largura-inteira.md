# ADR 0248 — 页面内容占满整个宽度

- **状态：** 已接受
- **日期：** 2026-11-03
- **修订：** [ADR 0244](0244-coluna-das-abas-do-projeto-alinhada-a-esquerda.md)，涉及最大阅读宽度。

## 背景

在 Chrome（1848x981）中测得，每个标签页的内容大约在屏幕一半处结束：`ProjectPage` 的 `.coluna` 为 `max-width: 1040px`，账户页为 720px。所有者（11/03）认为这是排版糟糕的页面，"没有延伸到尽头"。

## 决定

1. 项目标签页和账户页的内容占满侧边栏右侧的整个宽度，保留现在的横向 padding。账户页的 `.coluna` 和 `.page` 没有 `max-width`。
2. **组件**的界限保留：长文本段落（`62ch`）、问题卡片（560px）、模态框和表单字段。
3. 代码标签页和会话界面不变。

## 后果

- 在宽屏上，表格行和卡片会被拉伸；长文本的阅读仍由段落的 `ch` 保护。
