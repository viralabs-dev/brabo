# ADR 0238 — 架构页的模块图变为 Canvas（`@xyflow/react`）

- **状态：** 已接受
- **日期：** 2026-11-02

## 背景

AT-683（所有者的决定，2026 年 11 月 2 日）批准把架构标签页中的模块卡片列表换成图。vault 的 v5 预览展示了可运行的 Canvas；其中的 ⚠️（节点标题带有整个 stack、深色主题下缩放控件为白色）已在此修复。

## 决定

1. `apps/web` 新增依赖：`@xyflow/react`（解压后约 1,2 MB）。
2. 实测体积：独立 chunk，约 42 KB gzip。`GrafoDeModulos` 通过动态 `import()`（`React.lazy`）加载它，模式与 ADR 0234 和 AT-300 相同，因此它的任何内容都不进入初始加载。
3. 图由当前的 `module_map`（RN-149）**推导**：节点 = 模块，边 = `dependsOn`（不存在的依赖被忽略）。绝不重新输入。
4. 节点标题 = 模块名；stack 以较小的、被截断的文字显示。颜色和缩放控件来自 `var(--…)` token，绝不是十六进制，两种主题皆然。
5. 模块卡片仍保留在图的下方。

## 后果

- 需要在 `pnpm audit` 中多跟踪一个依赖。
- 没有模块时，仍显示空状态文本。
