# ADR 0238 — Граф модулей вкладки Arquitetura становится Canvas (`@xyflow/react`)

- **Статус:** принято
- **Дата:** 2026-11-02

## Контекст

AT-683 (решение владельца, 02.11.2026) одобрила замену списка карточек
модулей вкладки Arquitetura графом. Превью v5 из хранилища показало работающий Canvas;
его ⚠️ (заголовок узла со всем стеком, белые элементы масштабирования
в тёмной теме) исправлены здесь.

## Решение

1. Новая зависимость в `apps/web`: `@xyflow/react` (~1,2 МБ в распакованном виде).
2. Измеренный вес: собственный чанк ~42 КБ gzip. `GrafoDeModulos` загружает его
   динамическим `import()` (`React.lazy`), по образцу ADR 0234 и AT-300,
   так что ничего из него не попадает в начальную загрузку.
3. Граф ПРОИЗВОДЕН от актуального `module_map` (RN-149): узлы = модули, рёбра
   = `dependsOn` (несуществующая зависимость игнорируется). Никогда не вводится заново.
4. Заголовок узла = имя модуля; стек идёт меньшим усечённым текстом. Цвета
   и элементы масштабирования берутся из токенов `var(--…)`, никогда из hex, в обеих темах.
5. Карточки модулей остаются под графом.

## Последствия

- Одной зависимостью больше для отслеживания в `pnpm audit`.
- Проект без модулей по-прежнему показывает текст пустого состояния.
