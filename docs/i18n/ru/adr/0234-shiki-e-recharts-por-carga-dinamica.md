# ADR 0234 — `shiki` в Code Block и `recharts` в Chart, всегда динамической загрузкой

- **Статус:** принято
- **Дата:** 2026-11-01
- **Пересматривает:** обоснование «без зависимости» для подсветки кода по regex
  (`MarkdownMessage`, вкладка Code) и для графика на собственном SVG
  (`SpendCharts.tsx`); [ADR 0232](0232-shadcn-com-base-ui-no-apps-web.md)
  остаётся в силе полностью
- **Предыдущий контекст:** [ADR 0068](0068-diagrama-c4-do-arquiteto.md) и
  [ADR 0103](0103-runner-local-execucao-na-maquina-do-usuario.md) (образец тяжёлой зависимости
  за `import()`), [ADR 0074](0074-tema-alcancavel-e-o-boot-sob-csp.md) и
  [ADR 0181](0181-tema-preto-neutro.md) (две темы, контраст как нижний предел)

## Контекст

Внедрение shadcn/AI Elements (AT-636) содержит четыре дополнения, которые владелец
разрешил 31.10 (решение 4): ⌘K, `shiki` в Code Block, `recharts` в Chart расходов и
`@shadcn/react` в Questionnaire. ⌘K вышел без новой зависимости (`Autocomplete`
из `@base-ui/react`, уже установленного, вместо `cmdk`, который притащил бы
Radix), а `@shadcn/react` вошёл в AT-653. Остаются две зависимости с весом,
измеренным в обследовании от 01.11 (esbuild + gzip): `shiki@4.5.0` (ядро ~55 КБ
gz, от 0,1 до 16 КБ на язык; 44 транзитивных пакета; MIT) и
`recharts@3.8.0` (~105 КБ gz; 37 транзитивных с разрешительной лицензией). `pnpm
audit --prod`: ноль уязвимостей у обеих.

## Решение

1. Обе входят в `apps/web` с ТОЧНОЙ версией и НИКОГДА не в начальный JS и не в
   `codeSplitting.groups` (список разрешённых): только через `import()`/`React.lazy`,
   в чанке тех, кто их использует.
2. `shiki` живёт за `lib/realce-shiki.ts`: `shiki/core` с движком regex на JS
   (без WASM), язык по требованию, собственная тема с
   `var(--syntax-*)` (без hex, в обеих темах). Нынешняя подсветка по regex остаётся
   запасным вариантом: пока `shiki` загружается и для языка, которого он не знает.
3. `recharts` живёт за `GraficoDeGastoPorDia.tsx` (lazy), только в дневных
   рядах расходов, с нынешним SVG как запасным вариантом и альтернативной таблицей рядом.
   Его нельзя импортировать из `SpendCharts.tsx`, который импортирует и вкладка Sessões.
4. Цвет графика и подсветки берётся из токена (`var(--accent)`, `var(--syntax-*)`);
   цвет, который должен выйти из CSS, проходит через `lib/tokens-padrao.ts`.

## Последствия

- Начальный JS не меняется; кто не открывает экран Gastos или блок кода,
  ничего нового не скачивает. Каждый PR, трогающий эти экраны, измеряет чанк до и после.
- Две зависимости для сопровождения, с `overrides`, если появится транзитивное предупреждение
  (дисциплина `pnpm-workspace.yaml`).
- Если одна из двух уйдёт, запасной вариант (regex, SVG) уже в коде.
