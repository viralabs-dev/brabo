# ADR 0260 — Документация репозиториев с кодом только на английском; сайт отдаёт английский источник с полосой

- **Статус:** принято
- **Дата:** 2026-11-05
- **Тема:** `docs`
- **Ссылки:** пересматривает ADR [0216](0216-quatro-idiomas-com-pt-br-como-fonte.md) (источник pt-BR действует только для `brabo`), [0219](0219-referencia-entra-na-traducao.md) (контракт `idioma_original: en` становится обычным путём для соседних репозиториев) и [0220](0220-api-traduzida-por-catalogo.md) (каталоги переезжают в `brabo`). AT-745, EP-033, решение владельца от 05.11.2026: «единственная документация, которая останется более чем на одном языке, — это входная дверь для клиента, то есть `brabo`; остальные репозитории — всё на английском».

## Контекст

ADR 0216 сделал pt-BR источником ВСЕЙ документации, а `en`, `ru` и `zh-Hans` — переводами в `docs/i18n/`. После разделения на одиннадцать репозиториев (EP-033) десять репозиториев с кодом несут это правило, хотя аудитории, которая бы его требовала, нет: их источник на 94–100% на pt-BR, копии `i18n/en` датируются 15.10 и устарели (в api нет 47 RN, в engine — 22, в web — 22), а проверки языка нет ни у одного из них. Только `brabo` — входная дверь клиента и публикует сайт.

Контракт, который это позволяет, уже существовал: `idioma_original: en` во frontmatter (AT-564, ADR 0219), его читает `faixa-de-traducao-check.mjs`, но не `paginas.mjs`.

## Решение

1. **Документация 10 репозиториев с кодом — только на английском.** `docs/`, `README`, `CHANGELOG` и файлы сообщества. Новая документация и новые RN пишутся на английском и без `docs/i18n/`. Их `CLAUDE.md` и `.claude/` остаются на pt-BR (решение владельца). Комментарии в коде и сообщения коммитов этим ADR не меняются.
2. **`brabo` остаётся многоязычным** (источник pt-BR, `en`, `ru`, `zh-Hans`, ADR 0216), включая документацию области `ci` в `scripts/ci/docs/`.
3. **Страница соседнего репозитория на английском несёт `idioma_original: en`.** В `/en/` сайт отдаёт сам источник, без полосы. В pt-BR, `ru` и `zh-Hans` он отдаёт ТОТ ЖЕ английский источник с новой полосой «эта страница существует только на английском». Если у соседнего репозитория ещё есть перевод для локали, он действует в этой локали: механизм допускает смешанное состояние, страница за страницей.
4. **Что идёт вместе с механизмом:**
   - индекс RN каждой локали берёт перевод, когда его файл существует, и источник, когда нет, чтобы RN соседних репозиториев не терялись;
   - генерируемый блок в источнике с `idioma_original: en` выходит с английскими текстами;
   - `paridade-de-traducao` не считает страницу с `idioma_original: en` переводимой (AT-735 остаётся без предмета);
   - фразы в прозе соседних репозиториев, которые `docs:check` привязывает к коду (`contagens-do-codigo.mjs`, runbook), принимают текст на pt-BR ИЛИ на английском, чтобы конвертация не ослепила проверку.
5. **Справочник API остаётся переведённым.** Владелец сохранил страницу Redoc на четырёх языках; каталоги `openapi-textos.json` уходят из `brabo-api` и живут в `brabo`, в `docs/i18n/<locale>/`.

## Последствия

- Каждый соседний репозиторий конвертирует документацию на английский в своей полосе, повышая `i18n/en` до источника RN за RN и удаляя `docs/i18n/`; `ru` и `zh-Hans` соседних репозиториев удаляются (git их хранит).
- Пока соседний репозиторий не сконвертирован, сайт показывает источник pt-BR с обычной полосой. После конвертации русский или китайский читатель видит английский с новой полосой.
- `RNS_SEM_TRADUCAO` в `links.mjs` остаётся: индекс возвращается к источнику по ФАЙЛУ, а не по RN, поэтому RN, отсутствующая в частичном переводе, всё ещё ломает якорь в локали, пока полоса соседнего репозитория не удалит `i18n/`.
- **Защита реализована (Раунд 201):** `scripts/docs/idioma-dos-irmaos.mjs`, вызываемый `docs:check`, не пропускает страницу `.md` в корне документации соседнего репозитория без `idioma_original: en`, а также любой `i18n/` в таком корне, называя файл и этот ADR. Корни самого `brabo` (`docs/`, `scripts/ci/docs/`) остаются многоязычными. Счётчик pt-BR (служебные слова и `ção`/`ções` вне кода, цитат, URL и ссылок) предупреждает, не отклоняя, если на странице с `en` остаётся португальский текст; на текущей документации он показывает ноль строк.

### Английские фразы, которые копируют полосы перевода

Ниже фразы, которые распознают новые шаблоны. Число пишется словом, строчными (сравнение не учитывает регистр).

| файл (репозиторий) | фраза на pt-BR | фраза на английском |
|---|---|---|
| `deploy/docs/runbook.md` (infra) | `as cinco imagens que o produto publica já estão resolvidas` | `the five images the product publishes are already resolved` |
| `apps/api/docs/reference/git-providers.md` (api) | `O contrato tem **quinze operações** —` | `The contract has **fifteen operations** —` |
| `apps/api/docs/reference/git-providers.md` (api) | `implementar todas as quinze operações, declarando` | `implement all fifteen operations, declaring` |
| `apps/api/docs/reference/artifacts.md` (api), no frontmatter | `description: Os doze schemas de artefato` | `description: The twelve artifact schemas` |
| RN (infra) | `- as **cinco imagens** são assinadas **por DIGEST**` | `- the **five images** are signed **by DIGEST**` |
| RN (infra) | `- as cinco imagens vêm de **variável obrigatória**` | `- the five images come from a **required variable**` |

Шаблон для `.claude/rules/broker-e-containers.md` (infra) остаётся только на pt-BR, потому что `.claude/` остаётся на pt-BR.

## Рассмотренные альтернативы

- **Отдавать соседний репозиторий на английском БЕЗ полосы в других локалях.** Отклонено: русскоязычный читатель должен знать, что страница не на его языке.
- **Скрывать страницы только на английском из `ru` и `zh-Hans`.** Отклонено: ссылки между страницами сломались бы, а поиск потерял бы техническую справку.
- **Сохранить три перевода соседних репозиториев.** Отклонено владельцем: три копии на каждое изменение, без читателя и уже устаревшие.
