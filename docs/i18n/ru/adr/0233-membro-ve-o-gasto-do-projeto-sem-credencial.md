# ADR 0233 — Участник видит расходы проекта по агентам и областям, никогда по провайдерам

- **Статус:** принято
- **Дата:** 2026-10-31
- **Пересматривает:** [ADR 0063](0063-duas-audiencias-para-o-mesmo-gasto.md) (две
  аудитории одного расхода) в части, где участник видел только СОБСТВЕННОЕ
  потребление; [ADR 0076](0076-provider-volta-a-ser-dimensao-de-gasto.md) остаётся
  в силе полностью (провайдер — ось owner и вне досягаемости по типу)
- **Предыдущий контекст:** [RN-058](../business-rules/api.md#rn-058),
  [RN-060](../business-rules/api.md#rn-060),
  [RN-101](../business-rules/api.md#rn-101),
  [RN-187](../business-rules/api.md#rn-187)

## Контекст

Просьба владельца (AT-632, 31.10) разделяет страницу расходов на ГЛОБАЛЬНУЮ и НА
ПРОЕКТ. ADR 0063 оставлял участнику только `spend/me` (собственное потребление как
актора), хотя стоимость по агентам уже видна `developer` в Настройки >
Модели. Решение владельца: участник видит ИТОГО по проекту и стоимость по
агентам/областям, без провайдера и учётных данных.

## Решение

1. `GET /projects/:projectId/spend/team` (`viewer`): итог проекта и стоимость по
   агентам и по областям каталога. Область — проект, без актора, но use case
   запрашивает только измерение `actor`; в маршруте нет параметра измерения.
   Провайдер и учётные данные остаются исключительно у owner (RN-060, RN-186).
2. `GET /workspaces/:workspaceId/spend/me` (`viewer`): СОБСТВЕННОЕ потребление,
   сложенное по проектам, для не-owner на глобальной странице. Область актора, поэтому
   `provider` даже не компилируется (RN-187).
3. Отчёт owner получает `?projectId=` (404 для проекта другого
   workspace) и измерение `session`.
4. Курируемая метка `billing` (`api|subscription|free`) в `models` отделяет
   `assinaturaMicros` от оплаченных US$.

## Последствия

- Участник начинает видеть, сколько команда (агенты) потратила на проект. Это факт
  проекта, а не счёта по ключу; счёт остаётся у owner.
- Чего участник НЕ получает: провайдера, учётные данные, потребление другого человека.
- Отказ в `CriativoKpis` (web) перестаёт быть правилом; экран — за lane web.
