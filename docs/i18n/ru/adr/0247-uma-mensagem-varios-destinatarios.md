# ADR 0247 — Одно сообщение, несколько адресатов

- **Статус:** принято
- **Дата:** 2026-11-03
- **Ссылается на:** ADR [0163](0163-o-clique-responde-ao-aceitar.md) (ответ при принятии) и [0191](0191-a-mensagem-com-turno-em-curso-entra-numa-fila.md) (очередь на агента). Пересматривает RN-584 и RN-631 (только один адресат на сообщение). Ни один ADR не редактируется.

## Контекст

AT-717 (EP-031): `@` в composer. Владелец решил 02.11, что `@po @arquiteto` отправляет ТО ЖЕ сообщение обоим. До сих пор у сообщения был один адресат, выбираемый в селекторе «Para» (RN-631), и `chat.message` не говорило, кому оно ушло.

## Решение

1. **Новый маршрут** `POST /projects/:projectId/sessions/:sessionId/messages` (`developer`), тело `{ text, destinatarios: string[] (1 до 7), anexos? }`, 202 с `{ mensagemId, entregas: [{ agente, entrega: 'turno'|'enfileirada'|'recusada', motivo? }] }`. Маршрут одного агента (`.../agents/:agent/message`) не меняется.
2. **ОДИН `chat.message`** с `payload.destinatarios`. Маршрут одного агента теперь записывает `[agent]`, и лог говорит, кому ушло каждое сообщение.
3. **Одна доставка на агента, с ТЕМ ЖЕ `mensagemId`**, по уже существующему пути (`agent/message` engine, `TurnoAssincrono`, очередь RN-673, именованные отказы). Новой очереди нет. Отказ одного адресата (не разговорный, неактивный, очередь заполнена) становится `recusada` с причиной и не роняет остальных. Завершённая сессия по-прежнему 409 `sessao_encerrada` (RN-581), до любой доставки.
4. **Общий `mensagemId` требует области по агенту в очереди**: `chat.message_delivered` (актор = агент) и `chat.message_cancelled` (`agente` в payload) закрывают только копию того агента, к которому относятся. Старое событие без `agente` действует для всех.
5. **Регидратация:** `chat.message` уже входит как сообщение пользователя в историю каждого агента; адресаты читают его как адресованное им, а для не-адресатов ничего не меняется.

## Последствия

- Каждый адресат оплачивает ход; экран сопровождает более одного хода (lane web).
- Агенты, не являющиеся адресатами, по-прежнему не читают вживую; только при регидратации.
- RN-584 (именованный отказ) и RN-631 (селектор одного адресата) остаются в силе по каждому адресату.
