# ADR 0242 — Containers в линейной таблице с `@tanstack/react-table`

## Статус

**Принято.** 2026-11-02 (AT-714; v7 одобрена владельцем).

## Контекст

v7 заменяет карточки Containers и Providers линейной таблицей (одна строка на
элемент, действия только иконками с `legenda`). Containers нужно сортировать и разбивать на страницы.

## Решение

- Containers использует `@tanstack/react-table` (`^9.3.1`, вход `legacy`) только для
  определения порядка и страницы на КЛИЕНТЕ; новых запросов нет. Providers остаётся
  в линейной таблице на существующем компоненте `Table`, без библиотеки.
- Обоснование новой зависимости, измеренное в `vite build`: экран — собственный
  чанк (`ContainersPage` 4,4 кБ, 1,7 кБ gzip), а библиотека попадает в группу
  вендоров `vendor-tanstack` (236 кБ, 66 кБ gzip всего, с router и query, уже
  существующая); изолированная дельта библиотеки не измерялась. `pnpm audit --prod`:
  известных уязвимостей нет; ~140 кБ на диске в `node_modules`.

## Последствия

Ещё одна зависимость для сопровождения; будущая таблица, которая только перечисляет, в ней не нуждается.
