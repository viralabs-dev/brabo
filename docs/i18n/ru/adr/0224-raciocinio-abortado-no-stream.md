# ADR 0224 — Рассуждение считается в потоке и обрывается на лимите, а стоимость оценивается и сверяется

## Статус

**Принято.** 2026-10-22 (AT-589, EP-026, решения владельца). Тема: `llm`.
Дополняет, не редактируя его, [0223](0223-orcamento-de-raciocinio-por-modelo.md) и использует
колонку `price_implicit` из [0188](0188-o-custo-real-do-provider-vira-o-numero-do-metering.md).

## Контекст

[0223](0223-orcamento-de-raciocinio-por-modelo.md) ограничивает только тех, кто соблюдает поле
`reasoning.max_tokens`. `deepseek/deepseek-v4.1-flash` игнорирует любое поле лимита
(8192 рассуждения из 8192), и AT-589 родилась ради него: обрыв соединения в
потоке — единственный способ его ограничить. Платное измерение от 22.10 (OpenRouter): каждый чанк
рассуждения несёт `delta.reasoning` (текст); `символы/4` приближает токены (3,9 у
deepseek, 3,8 у qwen); обрыв тарифицирует только уже сгенерированное (~521 из 529 токенов). Но
оборванный ответ НЕ несёт ни `usage`, ни `finish_reason`, а реальная стоимость появляется только в
`GET /api/v1/generation?id=` примерно через 5 минут (раньше — 404).

## Решение

1. OpenAI-совместимый провайдер считает `delta.reasoning` (символы/4), когда у модели
   есть `reasoning_budget`, и при превышении лимита обрывает соединение и отправляет чанк
   `truncated` с `motivo: "raciocinio"` (усечение по `max_tokens` motivo не имеет).
   Модель без бюджета не считает и не обрывает.
2. Расход оборванного вызова = ОЦЕНКА НА МЕСТЕ: выходные токены = символы/4 (рассуждения
   и текста), входные — по оценщику (или символы/4, если его нет), по цене каталога, с
   `price_implicit` и новой `token_usage.custo_a_reconciliar`.
3. СВЕРКА: `ReconciliarCustoEstimadoUseCase` запускается через `setInterval` в самом
   процессе api (тот же механизм, что у проекторов; без новой очереди, без Redis), каждые
   `CUSTO_RECONCILIACAO_INTERVAL_MS` (5 мин; `0` отключает). Смотрит только помеченные строки
   за последние 24 ч и заменяет их на `total_cost` из `/generation` только при 200;
   замененная строка хранит оценку в `catalog_cost_micros`. Любой другой ответ оставляет
   строку до следующего прохода; через 24 ч оценка становится окончательной.
4. Миграция 0075 создаёт колонку и ставит `reasoning_budget` 2048 для
   `deepseek/deepseek-v4.1-flash` (openrouter), по образцу 0074.

## Последствия

- Контракт провайдера получает `truncated.motivo` и `usage.abortadoPeloRaciocinio`
  (аддитивно); метеринг получает колонку.
- Заявленные пределы: `spentMicros` бюджета и области НЕ корректируется сверкой
  (оценка уже его увеличила; разница в копейках); используется ключ owner
  workspace; несколько экземпляров api сверяют параллельно без вреда (замена
  действует только на ещё помеченную строку); частичные tool call из оборванного потока
  отбрасываются.
