# ADR 0253 — Сайт документации отказывается от Docusaurus

- **Статус:** принято
- **Дата:** 2026-11-04
- **Тема:** `docs`
- **Ссылается на:** ADR [0117](0117-lockfile-proprio-para-o-website.md), [0206](0206-referencia-da-api-numa-pagina-redoc.md), [0216](0216-quatro-idiomas-com-pt-br-como-fonte.md) и [0220](0220-api-traduzida-por-catalogo.md). Ни один из них не редактируется.

## Контекст

Сайт документации — это Docusaurus 3, читающий `docs/` (AT-662, EP-031, решение владельца от 02.11.2026). Фреймворк тянет дерево зависимостей, которое никогда не попадает ни в один образ и уже потребовало изолированного lockfile (0117) и девятнадцати overrides, индекс поиска весит около 25 МБ на язык, а тема следует Infima, а не дизайн-системе продукта. Образец собственного генератора уже есть в `site/` проекта Smartsky (около 1,3 тыс. строк, `markdown-it`, без фреймворка).

## Решение

1. **Собственный генератор** в `scripts/docs/site/` (ESM, `markdown-it` и `shiki` в `scripts/package.json`), с выводом в `build/docs-site/`, относительными путями и ТЕМИ ЖЕ URL и якорями `{#id}`, что у нынешнего сайта (`x.md` становится `x.html`, `pasta/index.md` становится `pasta.html`, `intro` становится `index.html`, остальные языки — под `/<locale>/`). Каждый язык собирается с ПОЛНЫМ набором страниц (перевод или исходник pt-BR по тому же адресу), поэтому ссылка никогда не покидает язык.
2. **Справочник API остаётся на Redoc 3**, с текстом spec, переведённым каталогом по хэшу из 0220 (который не меняется), и **явно отключённой телеметрией**. Redoc 3 убрал опцию `labels`: подписи ИНТЕРФЕЙСА Redoc (Request samples, Responses…) возвращаются на английский на четырёх языках, цена, принятая владельцем. 0206 меняет рендерер (без redocusaurus), а 0220 сохраняет каталог.
3. **Переводы переезжают в `docs/i18n/<locale>/`**, перестав жить в `website/i18n/…/docusaurus-plugin-content-docs/current/` (паритет, `openapi-textos.json` и руководства следуют новому пути). Путь — константа генератора.
4. **Поиск по подстроке**, нормализованный, без стемминга, с индексом на язык, загружаемым только когда человек ищет; страница API сохраняет поиск Redoc.
5. **0117 теряет предмет**, где в `website/` больше нет Docusaurus; изоляция lockfile сохраняется только для дерева Redoc.
6. **Сохраняются:** публикация по ступеням из 0073, четыре языка и источник pt-BR из 0216, `noindex` вне `main`, предупреждение о тестовой фазе, «править эту страницу» и «последнее обновление».

## Последствия

- Теряются ранжирование поиска lunr, подсветка термина на целевой странице и `search.html`.
- Миграция поэтапная: генератор работает рядом (`pnpm docs:site`) до замены CI и deploy, которая является одним PR.
- CLAUDE.md и части контекста, упоминающие Docusaurus, меняются при замене, а не до неё.
