# ADR 0249 — Рассуждение агента записывается и показывается только developer и выше

- **Статус:** принято
- **Дата:** 2026-11-03
- **Ссылается на:** ADR [0224](0224-raciocinio-abortado-no-stream.md) (рассуждение СЧИТАЕТСЯ в потоке, а не хранится) и [0041](0041-base-openai-compativel-e-contrato-de-llm-providers.md) (capability только с доказательством). Ни один ADR не редактируется.

## Контекст

AT-676 (EP-031): блок «Рассуждение» в ленте не имел данных. Текст уже приходил в `delta.reasoning` и отбрасывался. Владелец решил 03.11: записывать ЦЕЛИКОМ, показывать и вживую, видит только `developer` и выше, и действует для OpenRouter, Anthropic и `reasoning_content`.

## Решение

1. **Контракт.** `ChatStreamChunk` получает `{ type: 'reasoning', text }`, а `LLMProviderCapabilities` получает `reasoningText`, `false` у всех, пока нет smoke (код чтения у провайдеров есть; флаг говорит лишь о том, что ДОКАЗАНО).
2. **`stream-llm-turn`** отправляет кадр `raciocinio` с дельтой, а `final` несёт полное `raciocinio`, без обрезки; `llm-turn` возвращает то же поле. Текст никогда не попадает в `content`.
3. **Anthropic.** Отправляет `thinking` (`budget_tokens` = бюджет модели, минимум 1024), и потолок вывода поднимается на это значение. Подписанные блоки `thinking`/`redacted_thinking` выходят в чанке `tool_calls` (`thinkingBlocks`) и в `final` (`message.thinkingBlocks`); engine хранит их между витками цикла и возвращает в `ChatMessage.thinkingBlocks`, которые провайдер ставит ПЕРЕД текстом и `tool_use`.
4. **Запись.** Engine записывает `payload.raciocinio` в `agent.response`, без потолка. Никогда не возвращается модели (регидратация), в RAG и в граф.
5. **Кто читает.** Api убирает `payload.raciocinio` из HTTP-чтений событий для тех, чья эффективная роль ниже `developer`, единым фильтром вывода; живой канал engine требует той же роли, выдаваемой в тикете сокета.

## Последствия

- Рассуждение может повторять то, что агент прочитал; ограничение по роли — это сдерживание, по образцу `tool.result` (RN-589) на одну ступень выше.
- Без потолка событие растёт (до бюджета на виток, до 14 витков). Размер объявляется в payload lane engine.
- Провайдеры без smoke остаются с `reasoningText: false` и деградируют без блока.
