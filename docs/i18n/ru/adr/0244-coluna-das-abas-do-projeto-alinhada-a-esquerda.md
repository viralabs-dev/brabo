# ADR 0244 — Колонка вкладок проекта выровнена по левому краю

- **Статус:** принято
- **Дата:** 2026-11-03
- **Пересматривает:** [ADR 0078](0078-moldura-de-tela-e-o-registro-de-abas-diverge-do-handoff.md) в части колонки содержимого, центрированной на 1040px.

## Контекст

Вкладки проекта рисовали содержимое в колонке 1040px по центру
(`margin: 0 auto`), тогда как заголовок был слева. Владелец (AT-720,
03.11) попросил выровнять содержимое по заголовку.

## Решение

1. `.body` в `ProjectPage.module.css` сохраняет `max-width: 1040px` (ширина
   для чтения) и теряет центрирование: колонка начинается слева.
2. Вкладка Code и вкладки `semRespiro` не используют колонку (ADR 0211/0241) и не меняются.

## Последствия

- На широких экранах справа остаётся место, намеренно.
