# Как мы пишем документацию

**После прочтения:** вы напишете страницу, которая проходит проверку стиля без чужой помощи.
**Прежде чем начать:** знайте тип страницы (туториал, руководство, концепция или справочник) и имейте клонированный репозиторий с выполненным `pnpm install`.

## Правила

1. **Короткие предложения, активный залог.** Стремитесь к 20 словам в предложении. Говорите «установщик записывает файл», а не «файл записывается установщиком».
2. **Одна мысль на абзац.** Если в абзаце два «кроме того», это два абзаца.
3. **Начинайте с того, что человек сможет сделать.** Сразу после заголовка напишите «После прочтения» и предварительные требования, как на этой странице.
4. **Сначала «как», потом «почему».** Начните с того, что делать. Причина идёт потом, коротко и только если помогает решить.
5. **Нумерованные и проверяемые шаги.** Каждый шаг — одно действие. Завершайте процедуру пунктом «как понять, что получилось»: команда и ожидаемый результат.
6. **Внутренние ID только в «Para saber mais».** ADR, RN, AT, EP, HS, Fase и Rodada остаются в разделе `## Para saber mais` в конце страницы. В основном тексте передавайте мысль словами.
7. **Изображения только из манифеста изображений.** Не вставляйте на страницу случайные скриншоты. Скрывайте чувствительные данные на любом снимке.
8. **Секрет не появляется никогда**, даже пример, похожий на настоящий. Используйте `<TOKEN>`.

## Бюджет по типам

Тип берётся из поля `tipo:` во frontmatter. Считается только проза: frontmatter, блоки кода, таблицы, заголовки и раздел «Para saber mais» не учитываются.

| Тип | Лимит слов |
|---|---|
| туториал | 1 500 |
| руководство | 800 |
| концепция | 1 200 |
| справочник | без лимита, с оглавлением |

Превысили лимит? Разделите страницу на две или вынесите детали в справочник и оставьте ссылку.

## Запустить проверку

В корне репозитория:

```bash
node scripts/docs/estilo.mjs                          # todas as páginas
node scripts/docs/estilo.mjs docs/contribuir/como-escrevemos.md
```

Проверка печатает один `AVISO` на страницу выше лимита и по одному на внутренний ID вне «Para saber mais». Пока она только предупреждает. Список `PENDENTES` в `scripts/docs/estilo.spec.ts` хранит старые страницы, которые всё ещё превышают лимит: он только сокращается. Новая страница или страница, которую вы только что поправили, должна проходить.

Как понять, что получилось: команда завершается строкой `estilo: 0 aviso(s)` для вашей страницы, а `pnpm test:scripts` выходит с кодом 0.

## Хороший образец

Путь `orquestrar-repositorios` следует этому руководству: он открывается разделом «Para quem é», его предложения содержат от 15 до 18 слов, а каждая страница укладывается в 825 слов. Скопируйте его формат.
