# How Brabo is built

**Who it's for:** anyone who wants to replicate Brabo's **way of working** in their own product, with or without AI agents. You don't need to know the project's history.

**After reading, you can:**
- set up a board with one epic and two tasks, one of them ready to start;
- run a round with discovery and execution that ends in a PR;
- tie each business rule to a file and a test;
- copy the templates and the sample agents.

**Reading time:** about 20 minutes; each page takes 3 to 5.

## Structure and method

The path [Orchestrating a product across many repositories](../orquestrar-repositorios/index.md) teaches the **structure**: how to split the product and how the repositories connect. This one teaches the **method**: how work comes in, moves and goes out. Anyone who copies only the structure ends up with eleven repositories and no rhythm.

The examples here are made up and neutral. Where there is real proof, the text links to a public PR, such as [PR 79 of `brabo`](https://github.com/viralabs-dev/brabo/pull/79), which published the structure path.
